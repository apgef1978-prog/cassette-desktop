# Десктоп-версия генератора вкладышей — план

Порт веб-приложения (`/home/pavel/cassette`) в десктоп-приложение под Windows.

## Зафиксированные решения

| Вопрос | Решение |
|---|---|
| Подход | **PyWebview + PyInstaller** — тот же Flask в нативном окне, переиспользуем ~весь код |
| Платформа | **Windows** (.exe) |
| Дистрибуция | **Один файл**, без установки (`--onefile --windowed`) |
| Сборка .exe | **GitHub Actions**, windows-runner (PyInstaller не кросс-компилит с Linux) |
| Вывод вкладышей | Папка **`Документы\Кассетные вкладыши`** |
| WebView | На Windows pywebview рендерит через WebView2 (Edge) — в Win10/11 рантайм есть по умолчанию |

## Архитектура обёртки (`main.py`)

1. Поднять Flask в фоновом потоке на свободном localhost-порту (без reloader, `debug=False`).
2. Открыть окно pywebview на `http://127.0.0.1:<port>`.
3. Корректно гасить процесс при закрытии окна.

## Рефактор путей (для `--onefile`)

- `make_insert.py:10` `TEMPLATE` — резолвить через хелпер `resource_path()` (учитывает `sys._MEIPASS`); шаблон класть в бандл через `--add-data`.
- `make_insert.py:168` `_build` и `app.py` `OUT=HERE/output` — перенести в пользовательскую папку `Документы\Кассетные вкладыши` (в бандле каталог рядом со скриптом недоступен на запись).
- `pdf_page_count` / `autosize` (LibreOffice) — в десктопе не используются, как и в вебе (берётся эвристика `auto_sz`).

## UX скачивания

Браузерный `<a download>` в нативном окне заменить на «Сохранить как…» через файловый диалог pywebview либо кнопку «Открыть папку с вкладышем».

## Этапы

- **Этап 1 (Linux, здесь):** `main.py`-обёртка, рефактор путей, UX скачивания, `.spec`/команда PyInstaller с `--add-data`. Тестируется в нативном окне на Linux.
- **Этап 2 (GitHub Actions):** workflow на windows-runner → сборка `.exe` (`--onefile`). **Предусловие:** репозиторий нужно запушить на GitHub (сейчас git только локальный, без remote).
