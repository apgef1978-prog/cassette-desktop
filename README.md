# Вкладыши для аудиокассет

Десктоп-приложение для Windows: собирает вкладыш (J-card) для аудиокассеты в `.docx`
по шаблону Word. Треклист и обложку можно найти в интернете, прочитать из папки с
музыкой или ввести руками; программа разложит треки по сторонам и подберёт размер
шрифта, чтобы вкладыш поместился на одну страницу.

## Возможности

- Поиск альбома в iTunes, Deezer и MusicBrainz (без ключей и регистрации).
- Чтение треклиста из папки: теги, точные длительности, обложка; поддержка CUE,
  FLAC/MP3/M4A/OGG/APE/WAV и DSD (`.dsf`, `.dff`).
- Раскладка по сторонам A/B: добивка тем же альбомом или микстейп из двух альбомов.
- Пресеты кассет (C60/C90, «стандарт J-card», свои размеры и минуты на сторону).
- Шрифты и размеры торца, треклиста и лицевой стороны; лицевая — картинкой или
  названием альбома текстом.
- Два макета: раздельные части и «вкладыш целиком одной полосой».
- Готовые файлы складываются в `Документы\Кассетные вкладыши`.

## Запуск из исходников

Нужен Python 3.12+.

```powershell
pip install -r requirements.txt
python main.py
```

Откроется нативное окно. Отдельно веб-режим (только localhost):

```powershell
python app.py          # http://127.0.0.1:8000
```

## Сборка .exe

PyInstaller не кросс-компилирует, собирать нужно на Windows:

```powershell
pip install -r requirements.txt pyinstaller
pyinstaller --noconfirm build.spec
```

Готовый файл — `dist\Vkladyshi.exe` (один файл, без установки).

Автоматическая сборка — GitHub Actions: пуш тега запускает проверки, сборку и
публикацию `.exe` в GitHub Release.

## Проверки

```powershell
python test_core.py    # или: python -m pytest test_core.py
```

Проверяются геометрия под пресеты, раскладка «целиком», шрифты, сборка без обложки
и распределение треков по сторонам. Эти же тесты гоняются в CI на каждый пуш.

## Где лежат данные

| Что | Где |
|---|---|
| Готовые вкладыши, обложки | `Документы\Кассетные вкладыши` |
| Пресеты кассет (правится в программе) | `Документы\Кассетные вкладыши\cassettes.json` |
| Шаблон Word | `Шаблон_вкладыш_ЧИСТЫЙ.docx` в репозитории (в .exe — внутри бандла) |

Шаблон не перезаписывается: программа правит копию и собирает новый `.docx`.
Пресеты при первом запуске копируются из бандла и дальше живут отдельно, поэтому
ваши размеры кассет переживают обновление.

## Ограничения

- Размер шрифта подбирается эвристикой (Word не рендерится), поэтому после
  генерации стоит открыть файл и убедиться, что всё на одной странице.
- Шаблон завязан на три таблицы и текстовые маркеры
  `ИСПОЛНИТЕЛЬ - НАЗВАНИЕ АЛЬБОМА (ГОД)` и `Side A:`. Если отредактировать шаблон
  в Word и маркеры пропадут, сборка завершится понятной ошибкой, а не тихо
  соберёт вкладыш с текстом-заглушкой.
- Поиск требует интернета; сами вкладыши генерируются локально, ничего не
  отправляется на сторонние серверы, кроме поисковых запросов и загрузки обложек.
